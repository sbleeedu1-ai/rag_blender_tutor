## 할 일 (하나씩, 하나가 끝나면 커밋)

1. **ruff**
   - `pyproject.toml`의 `dev`에 ruff를 넣고 `.venv/bin/python -m pip install -e ".[dev]"`.
   - 규칙을 켜지 않은 기본값으로 한 번 돌려(`.venv/bin/python -m ruff check .`) 지적 수를 규칙별로 센다. 아직 고치지 않는다.
   - 지적 수 표를 사용자에게 보이고 켤 규칙을 정한다(HISTORY [459] "처음 한 번 돌려 지적 수를 보고 켤 범위를 정함").
   - 정한 규칙만 `pyproject.toml`에 적고, 자동 고침은 규칙 하나씩 돌려 diff를 읽는다.
2. **mypy**
   - 같은 방식으로 넣고 한 번 돌려 지적 수를 파일별로 센 뒤, 켤 범위(전체 / `blender_tutor/`만 / 일부 파일)를 사용자와 정한다.
3. **코드 경계**
   - 검사할 규칙: `addon/blender_tutor_addon/` 아래 파일은 `blender_tutor`를 불러오지 않는다.
   - ruff의 금지 import 규칙이나 import-linter 가운데 설정이 짧은 쪽을 고른다. 고른 까닭을 HISTORY에 적는다.
   - 일부러 어기는 줄을 임시로 넣어 검사가 실패하는 것을 본 뒤 지운다.
4. **주석 줄이기**
   - 지우는 것: 바로 아래 코드를 말로 되풀이하는 주석.
   - 남기는 것: 까닭을 적은 주석, HISTORY 번호·실측 날짜가 든 주석, 독스트링.
   - 파일 하나씩 하고, 지운 줄 수를 파일별로 적는다. 헷갈리면 남긴다.
5. **CI에 붙이기**: `.github/workflows/test.yml`에 ruff·mypy·경계 검사 단계를 더한다.
