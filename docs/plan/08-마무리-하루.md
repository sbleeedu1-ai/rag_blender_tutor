### 0. 봉인한 문항으로 한 번 재기 (아침, 유료, 승인 뒤, 딱 한 번)

티켓 37의 완료 조건을 그대로 따른다.

- **봉인한 문항 자료는 사용자가 "지금 열어"라고 말하기 전에는 열지 않는다.** 위치도 찾아보지 않는다. 먼저 사용자에게 "얼린 커밋은 이것이고, 이제 봉인한 문항을 열어 한 번 돌려도 되는가"를 묻고, 사용자가 자료 위치를 알려 준다.
- 얼린 커밋에서 돌린다. 돌리기 전에 `git status`가 깨끗하고 `git rev-parse HEAD`가 07에 적은 번호와 같은지 본다.
- 문항은 20개다(정답형 12 / 없는 4 / 함정 4, 티켓 37의 2026-11-02 줄). 시간은 그중 10문항만 잰다.
- 07에서 개발 문항으로 점검해 둔 실행기를 문항 파일 경로만 바꿔 쓴다. 명령 앞에 `SSL_CERT_FILE=/etc/ssl/cert.pem`을 붙인다.
- **한 번만 돌린다.** 실패가 나도 다시 돌리지 않고 실패로 적는다(다시 돌려야 하는 사정이면 사용자에게 묻는다). 결과를 본 뒤 제품을 고치지 않는다. 틀린 것은 실패 사례로 쓴다.
- 채점: 07과 같은 방식(판 이름 가림, `answer-grader`, 노력치 medium, 이중 채점). 사용자가 어느 쪽 답인지 가린 채 따로 채점해 AI 채점과의 일치율을 낸다(티켓 37). HISTORY [318]의 사용자 몫 둘(갈린 답만 사용자가 판정하기, 5개쯤을 답대로 Blender에서 직접 따라 해 보기)을 05에서 하지 않았으면 여기서 함께 한다.
- GPT 빈손(도우미 없이 무료 웹 GPT에 같은 질문)도 잰다. 사용자가 직접 한다. 알아 둘 것: 무료 GPT는 웹 검색을 끌 수 없었다(HISTORY [396]-[408]). Q19 스크린샷은 다시 찍어야 한다(설정을 꺼도 버튼이 그려져 있었다).
- 도우미 창에서 잰 시간 10문항도 이때 잰다. 마우스와 외장 모니터가 있을 때 한다(HISTORY [331]).
- 네 칸 표를 채운다: GPT 빈손 / 고치기 전 / 고친 후(개발 문항) / 고친 후(봉인한 문항). 모든 숫자에 분모와 채점자를 적고, 검색 적중과 답 채점을 따로 적는다. 07에서 정한 "이겼다" 기준과 견준다. 기준에 못 미쳐도 숫자를 그대로 적는다.
