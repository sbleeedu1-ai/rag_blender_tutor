# 분류(Triage) 라벨

스킬들은 다섯 가지 기본 분류 역할로 말한다. 이 파일은 그 역할을 이 저장소에서 실제로 쓰는 라벨 문자열에 연결한다. 로컬 마크다운 트래커이므로 라벨은 각 이슈 파일의 `Status:` 줄에 적는다.

| mattpocock/skills 라벨 | 우리 트래커 라벨  | 뜻                                   |
| ---------------------- | ----------------- | ------------------------------------ |
| `needs-triage`         | `needs-triage`    | 담당자가 검토해야 함                 |
| `needs-info`           | `needs-info`      | 보고자에게 추가 정보를 기다리는 중   |
| `ready-for-agent`      | `ready-for-agent` | 명세가 완성되어 에이전트가 바로 작업 가능 |
| `ready-for-human`      | `ready-for-human` | 사람이 직접 구현해야 함              |
| `wontfix`              | `wontfix`         | 처리하지 않음                        |

스킬이 역할을 말하면(예: "에이전트 작업 가능 라벨을 붙여라") 위 표의 해당 라벨 문자열을 쓴다.

다른 이름을 쓰고 싶으면 "우리 트래커 라벨" 열을 고친다.
