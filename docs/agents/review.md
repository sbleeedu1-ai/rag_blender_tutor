# 검토 결과 처리

코드 검토나 다른 AI의 점검 결과를 받았을 때 따른다. 사용자가 "한꺼번에 정리해"처럼 방식을 바꾸면 그 말을 따른다.

## 기준이 있는 결과

`docs/agents/grading.md` 체크리스트처럼 기준이 이미 정해진 일의 결과는 Claude가 기준에 비춰 하나씩 판단해 반영한다. 사용자에게는 기준만으로 정할 수 없는 중요한 것 2개 안팎을 보이고, 반영한 나머지는 목록으로 알린다.

Blender 기능 내용 판단("이 청크가 질문의 답이 되나" 등)은 Claude가 본문을 읽고 근거와 권하는 답을 낸다. 목록은 빠짐없이 짧은 표로 보이고, 권하는 답을 기본값으로 묶어 한 번에 승인받는다. 사용자 판단은 실험 설계·범위·비용 같은 방향 결정에 모은다.

## 기준이 없는 결과

- 항목에 번호를 붙이고 검토자가 낸 수와 보여 준 수를 맞춘다. 버그와 사소한 것도 임의로 고치거나 넘기지 않고, 판단 전에는 검토 반영 커밋을 하지 않는다.
- 한 항목씩 글로(선택 창 없이) 근거, 지금 동작, 권하는 답을 보인다. 근거는 확인한 것과 아직 추측인 것을 가른다. 자료에 없다는 주장에는 실제 검색 결과를, 동작이 틀렸다는 주장에는 작은 입력과 실제 출력을 붙인다.
