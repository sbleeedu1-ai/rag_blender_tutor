# 검토 결과 처리

코드 검토나 다른 AI의 점검 결과를 받았을 때 따른다. 사용자가 "한꺼번에 정리해"처럼 방식을 바꾸면 그 말을 따른다.

## 기준이 있는 결과

`docs/agents/grading.md` 체크리스트처럼 기준이 이미 정해진 일의 결과는 Claude가 기준에 비춰 하나씩 판단해 반영한다. 사용자에게는 기준만으로 정할 수 없는 중요한 것 2개 안팎을 보이고, 반영한 나머지는 목록으로 알린다.

Blender 기능 내용 판단("이 청크가 질문의 답이 되나" 등)은 Claude가 본문을 읽고 근거와 권하는 답을 낸다. 판단은 advisor와 정해 반영하고, 목록은 끝에 빠짐없이 짧은 표로 보인다.

## 기준이 없는 결과

- 항목에 번호를 붙이고 검토자가 낸 수와 처리한 수를 맞춘다. 버그와 사소한 것도 빠짐없이 처리 칸을 채운다.
- 항목마다 근거, 지금 동작, 처리를 advisor와 정한다. 근거는 확인한 것과 아직 추측인 것을 가른다. 자료에 없다는 주장에는 실제 검색 결과를, 동작이 틀렸다는 주장에는 작은 입력과 실제 출력을 붙인다.
- 끝나면 사용자에게 번호 표 하나(지적, 처리, 근거)로 보인다. 실행 전에 묻는 일(`AGENTS.md`의 돈·병합·삭제, 사용자가 정한 것 바꾸기)에 걸리는 항목만 처리 전에 묻는다.

## 함께 확인할 것

- 화면·Blender·Windows를 흉내 낸 새 시험은 확인하려는 코드를 빼면 실패하는가(빼서 돌린 결과를 붙인다).
- `blender_tutor/`, `addon/`에서 하는 일이나 주고받는 모양이 바뀐 파일이 `STRUCTURE.md`에 반영됐는가.
