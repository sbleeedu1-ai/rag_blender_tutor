# 답 표기: 정한 꼴과 거부한 꼴

답(도우미 답·연습 과정 안내 말·번역 청크)에 Blender 이름을 어떤 꼴로 쓸지 이미 정한 것이다. 답 표기·화면 글자·괄호·조사를 바꾸거나 제안하기 전에 이 표를 먼저 보고, 제안과 함께 해당 줄의 HISTORY 번호를 든다. 표에 없는 새 꼴을 정하면 이 문서에 줄을 더한다(HISTORY는 경위, 이 문서는 지금 유효한 결정). 뒤집힌 결정은 최신만 남기고 옛 번호를 함께 적는다.

꼴을 바꾸는 코드는 커밋·유료 시험 전에 `.venv\Scripts\python .claude\tools\answer_diff.py`(Mac `.venv/bin/python .claude/tools/answer_diff.py`, 기본은 마지막 커밋 → 지금 작업 폴더)로 저장된 답 468개의 실제 전후 문장과 흐름 대조를 뽑아 보인다(HISTORY [371]).

범위: **메뉴** = 답·안내 말의 메뉴·버튼·옵션 이름(`[[ ]]`·맨 영어·모델이 옮긴 이름), **낱말** = 문장 속 일반 낱말, **청크** = 번역 청크(10-27-10-29 작업, 지금 도우미는 번역을 쓰지 않음 [104]). 상태: **됨** = 코드에 있음, **정함** = 결정만 있고 구현 전.

## 원하는 결과 ([353])

한국어 화면 사용자가 이름을 화면에서 바로 찾게 "화면 글자(영어)" 꼴. 문장은 사람이 읽기에 자연스럽게(겹친 괄호·지어낸 한국어·깨진 문장 없음). 화면 글자가 어색해도 화면 그대로. 지연은 늘리지 않음(답마다 모델을 더 부르지 않음). 사용자: "화면에 그렇게 나온다면 답 출력도 그렇게 하는게 맞다는건 아직도 유지중", "갑자기 모깎기 <- 화면에 보였던 단어도 아니고 이상한게 튀어나온거니까"(2026-11-16, [361]).
