# 답 표기: 정한 꼴과 거부한 꼴

답(도우미 답·연습 과정 안내 말·번역 청크)에 Blender 이름을 어떤 꼴로 쓸지 이미 정한 것이다. 답 표기·화면 글자·괄호·조사를 바꾸거나 제안하기 전에 이 표를 먼저 보고, 제안과 함께 해당 줄의 HISTORY 번호를 든다. 표에 없는 새 꼴을 정하면 이 문서에 줄을 더한다(HISTORY는 경위, 이 문서는 지금 유효한 결정). 뒤집힌 결정은 최신만 남기고 옛 번호를 함께 적는다.

## 원하는 결과 ([353])

한국어 화면 사용자가 이름을 화면에서 바로 찾게 "화면 글자(영어)" 꼴. 문장은 사람이 읽기에 자연스럽게(겹친 괄호·지어낸 한국어·깨진 문장 없음). 화면 글자가 어색해도 화면 그대로. 지연은 늘리지 않음(답마다 모델을 더 부르지 않음). 사용자: "화면에 그렇게 나온다면 답 출력도 그렇게 하는게 맞다는건 아직도 유지중", "갑자기 모깎기 <- 화면에 보였던 단어도 아니고 이상한게 튀어나온거니까".

## 아직 정하지 않은 것

- 목록이 못 잡는 모델의 풀어 쓴 말("옆면 개수(Vertices)")의 꼴: 후보 "옆면 개수, 곧 버텍스(Vertices)"를 저장된 답에 돌려 실제 문장을 보이기로 함(티켓 50).
- 규칙 가림을 붙일지: 붙이지 말자고 권함, 사용자 답 없음(티켓 50).
- 문장 속 '면'을 답에서도 '페이스'로: [78]은 번역 청크 결정. 답에는 티켓 50 뒤 단계 ⑤에서 넣음.
