# 0001. 채팅은 Blender 안이 아니라 Blender 위에 떠 있는 도우미 창으로

- 날짜: 2026-10-19
- 상태: 확정
- 근거 티켓: `.scratch/mvp-roundtrip/issues/01-애드온-왕복-시제품.md`

## 확정한 것

질문 입력과 답 표시는 Blender 위에 항상 떠 있는 작은 창(도우미 창)에서 한다. 애드온은 단축키(F10)를 받아 작업 상태를 읽고 도우미 창을 앞으로 부르는 일만 한다. 도우미 창은 작게, 정해진 자리에 뜨고, Esc로 Blender에 돌아간다.

## 이유

- Blender 5.2의 글자 칸은 Windows 기본 한국어 입력기로 한글이 제대로 안 들어간다(글자마다 화살표를 눌러야 함, 텍스트 에디터는 한영 전환도 안 됨). 강의실 PC에서 확인.
- Windows "이전 버전의 Microsoft IME 사용"을 켜면 거의 되지만, 초보자마다 Windows 설정을 바꾸게 해야 하고 Microsoft는 이 호환 설정에 오래 기대지 말라고 한다. 그래도 스페이스 두 번, 질문 창 Enter 두 번이 남는다.
- 도우미 창은 Windows 설정 없이 한글이 되고, Enter 한 번에 보내며, 긴 답도 저절로 줄바꿈된다. F10에서 입력 가능까지 약 0.1초라 "스크린샷 없이 바로 묻는다"는 핵심 근거를 해치지 않는다.

## 검토한 대안

- **Blender 안(N 패널 + 질문 창) + 설치 안내에 Windows 설정**: 만들 것은 가장 적지만 위 한글 문제 때문에 버림. Microsoft가 설정을 없애면 다시 막힌다.
- **웹 페이지(브라우저)**: 한글은 되지만 브라우저로 창을 옮겨야 해 시간 비교에서 불리. 사용자가 "웹 페이지 말고 오버레이로"를 제안해 떠 있는 창으로 바뀜.
- **3D 뷰 안에 겹쳐 그리기(뷰포트 오버레이)**: 입력이 여전히 Blender를 거쳐 한글 문제가 그대로. 이미 범위 밖(확장).

## 다시 볼 때

Blender가 Windows 새 한국어 입력기를 제대로 받게 되면 Blender 안 채팅을 다시 견줄 수 있다. 그 전에는 뒤집지 않는다.
