# 애드온 왕복 최소 시제품 (버릴 코드)

티켓: `.scratch/mvp-roundtrip/issues/01-애드온-왕복-시제품.md`. 이 폴더는 `prototype/01-addon-roundtrip` 브랜치에만 있고 main에 합치지 않는다.

가정: 이 시제품은 "어떻게 보여야 하나"(화면 시안 여러 개)나 "규칙이 맞나"(상태 흐름 HTML)를 묻는 것이 아니라 **"Blender 5.2에서 실제로 되나"**를 묻는다. 그래서 진짜 애드온 하나와 가짜 서버 하나로 만들었다.

## 실행

```
python prototype/addon_roundtrip/run.py            # 답 지연 2초
python prototype/addon_roundtrip/run.py --delay 5  # 멈춤 확인용
```

가짜 서버가 켜지고 Blender 5.2가 시제품 애드온을 단 채로 열린다. 터미널에는 서버가 받은 질문과 작업 상태가, 질문마다 시간(ms)이 찍힌다. Blender를 닫으면 서버도 꺼진다. 설치·설정 저장은 하지 않는다.

화면 없이 확인하는 부분만: `python prototype/addon_roundtrip/selftest_background.py`

## 눈으로 확인할 것 (사용자)

1. **시작 창**: Blender가 뜰 때 나오는 시작 창(최근 파일 목록)이 어떻게 생겼는지. 빈 곳을 눌러 닫는다
2. **N 패널**: 3D 뷰에서 `N` → 오른쪽 탭 `Tutor`에 "도우미 (시제품)"이 보이는지
3. **단축키**: 마우스를 3D 뷰에 두고 `F10` → 질문 창이 뜨는지, 클릭 없이 바로 글자를 칠 수 있는지, 한글이 입력되는지
4. **멈춤**: `--delay 5`로 켜고 질문을 보낸 뒤 5초 동안 화면을 돌리고(가운데 버튼 끌기) 물체를 골라 본다. 버벅이지 않는지, "심장 박동" 숫자가 계속 오르는지
5. **답 표시**: 답과 근거 링크가 채팅에 보이는지, 긴 글이 패널 폭에 맞게 줄바꿈되는지(패널 폭을 바꿔 보기)
6. **작업 상태**: Tab으로 편집 모드에 들어가 질문 → 서버 터미널에 `EDIT_MESH`가 찍히는지. 물체를 여럿 골라 질문
7. **한국어 화면**: 편집 > 환경 설정 > 인터페이스 > 언어를 한국어로. 패널의 "메뉴 이름 바꾸기 확인" 값이 실제 메뉴 글자와 같은지. 특히 편집 모드에서 `M`(병합) 메뉴의 "At Center"가 영어로 보이는지, 모디파이어 추가에서 Array가 어떻게 보이는지
8. **시간**: 패널 아래 "마지막 질문 시간"에서 "애드온 쪽 부담" 값
9. **강의실 PC**(GTX 950 2GB): 위 1-5가 같은지, Blender 5.2가 정상으로 뜨는지
