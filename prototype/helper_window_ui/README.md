# 도우미 창 화면 시제품: QML 판과 위젯 판 (버릴 코드)

근거: `.scratch/mvp-roundtrip/issues/26-도우미-창-왕복.md`, 조사 `archive/research/도우미-창-UI-도구-조사.md`, HISTORY [17]. 이 폴더는 `prototype/02-helper-window-ui` 브랜치에만 있고 main에 합치지 않는다.

묻는 것: **같은 모양을 PySide6 + QML로 만든 것과 파이썬 위젯만으로 만든 것 중 무엇으로 갈까?** 두 판은 모양·가짜 답이 같고 만드는 방식만 다르다.

## 준비(PC마다 한 번)

```
python -m venv .venv
.venv\Scripts\python -m pip install PySide6-Essentials
```

## 실행

```
.venv\Scripts\python prototype\helper_window_ui\run.py          # 두 판을 나란히(오른쪽 위젯, 왼쪽 QML)
.venv\Scripts\python prototype\helper_window_ui\run.py widgets  # 위젯 판만
.venv\Scripts\python prototype\helper_window_ui\run.py qml      # QML 판만
```

bash(Git Bash, Claude Code의 `!` 명령)에서는 `\` 대신 `/`를 쓴다: `.venv/Scripts/python prototype/helper_window_ui/run.py`

창 왼쪽 위에 "시제품 · 위젯" / "시제품 · QML"이 적혀 있다. 터미널에 보이기·보냄·첫 글자·답 끝 시간(ms)이 찍힌다. 끝내기: 트레이 아이콘 오른쪽 클릭 > 끝내기(판마다 아이콘이 하나씩).

## 눈으로 볼 것

1. **모양**: 어두운 반투명 판, 둥근 모서리, 회색 질문 / 굵은 흰 답, 근거 카드, 알약 입력칸. 어느 쪽이 더 마음에 드는지
2. **움직임**: 창이 뜰 때(X로 숨긴 뒤 트레이 왼쪽 클릭), 새 줄이 생길 때, "생각 중…" 깜빡임. QML 판에만 줄이 아래에서 올라오는 효과와 창이 살짝 커지는 효과가 있다
3. **한글 입력**: 입력칸에 빠르게 "안녕하세요 배열 모디파이어"를 쳐 보고 조합 중 글자가 칸 안에 보이는지, 글자가 빠지지 않는지. Enter로 보내기
4. **X 버튼**: 창 위에 마우스를 올리면 오른쪽 위에 나타나는지, 누르면 숨는지. Esc로도 숨는지
5. **트레이**: 숨긴 뒤 트레이(^ 안에 있을 수 있음) 왼쪽 클릭으로 다시 뜨는지, 입력칸에 바로 칠 수 있는지
6. **작업 표시줄·Alt+Tab**: 도우미가 나오지 않는지
7. **크기·옮기기**: 가장자리·모서리를 끌어 크기 조절, 맨 위 띠를 끌어 옮기기. 작게 줄여도 입력칸이 보이는지
8. **긴 답**: 질문을 세 번 보내면 세 번째가 긴 답이다. 줄바꿈과 스크롤
9. **근거 링크**: 누르면 브라우저에서 설명서가 열리는지

## 일부러 뺀 것

- Blender 따라가기(Blender가 앞일 때만 맨 위, 최소화 연동), F10: 시제품 01과 본 구현 26번에서 한다. 여기서는 늘 맨 위
- 진짜 배경 흐림: 조사대로 비활성 창에서 단색이 되므로 어두운 반투명 판으로 흉내만 냈다
- 처음 실행 때의 "보이기" 시간은 프로그램 시작 시간이 섞여 크다. X로 숨긴 뒤 트레이로 다시 부를 때 숫자를 본다

## 결론(2026-10-20): 위젯 판

- 사용자가 두 판을 강의실 PC에서 써 봄. 한글 입력("안녕하세요", "조오아쓰" 등)·X·트레이·크기 조절·근거 링크 모두 됨. 보기에는 "별 차이 없어보임".
- 측정(강의실 PC, 두 번 같은 값): 위젯 판 메모리 108MB·스레드 12·NVIDIA 드라이버 안 불러옴(CPU로 그림) / QML 판 147MB·스레드 28·NVIDIA 드라이버를 불러옴(GTX 950을 Blender와 나눠 씀). 다시 부르기 위젯 5-8ms, QML 9-20ms.
- 그래서 **PySide6 위젯(파이썬만)**으로 간다. 판 진하기 235/255, 답은 문장마다 줄바꿈. QML 판에서 난 실수(깜빡임이 멈출 때 글씨가 흐린 채 굳음, ListModel이 배열을 바꿈, 파이썬에서 QML 함수 부르기)는 참고로 남긴다.
