## 같은 티켓에 섞인 두 목적

| 작업 | 하려던 일 | 본문 전체 번역과의 관계 |
|---|---|---|
| 설명서 본문 한국어 번역 | 한국어 질문으로 관련 설명서를 더 잘 찾기 | 효과를 측정해야 하는 검색 보강책 |
| 메뉴 이름 한국어-영어 대응 | 한국어 질문의 메뉴를 영어와 연결하고, 답을 실제 화면 글자로 안내하기 | 본문을 전부 번역하지 않아도 따로 필요할 수 있는 기능 |

실제로 저장된 예를 확인했다. 근거는 [Array Modifier 설명서](https://docs.blender.org/manual/en/5.2/modeling/modifiers/generate/array.html#array-modifier)이며, 웹을 새로 조회하지 않고 내려받은 원문으로 대조했다.

| 자료 | 확인한 글 |
|---|---|
| 영어 청크 `data/chunks/manual_chunks.jsonl` | 제목 `Array Modifier`, 본문 시작 `The Array modifier creates multiple copies of an input geometry` |
| 번역 `data/translations/ko_none.jsonl` | 제목 `배열 모디파이어(Array Modifier)`, 본문 시작 `배열 모디파이어는 입력 지오메트리의 복사본을 여러 개 만들어` |

원문과 번역에 같은 기능을 가리키는 글을 두어 한국어 질문과 연결하려는 구조가 보인다. 다만 이 예는 저장된 글의 모습이며, 이 글이 검색에 더 잘 잡힌다는 측정 결과는 아니다.
