# 31 번역·메뉴 이름 검수에 쓸 모델과 실행 방식 조사

확인한 날짜: 2026-10-27 · 조사: Claude(Opus 5.5) 하위 에이전트 · 비용이 드는 호출은 하지 않았다(값은 모두 문서에서 읽은 것과 계산한 것).

## 한 쪽 요약

**결론.** 두 일 모두 **Claude Haiku 5.5, effort medium**으로 시작하는 게 맞다. 다만 실행 방식이 모델보다 더 중요하다.

- 돈으로 보면 (나) gpt-6-luna API와 (다) Haiku 5.5 API는 공식 가격이 **똑같다**(입력 $0.10·출력 $0.50/백만 토큰, Batch는 절반). 번역 전체도 **$1 아래**다(아래 표).
- (가) Claude Code 하위 에이전트로 Haiku를 띄우는 방식은 따로 돈이 들지 않는다. 대신 구독 **사용 한도**를 쓴다. 공식 문서는 "Haiku가 가장 가볍다"고만 하고 몇 배인지는 밝히지 않는다. 또 에이전트마다 시작할 때 드는 기본 토큰(지시문·도구 설명·CLAUDE.md)이 붙고, 지시를 쓰는 메인(Opus) 쪽 토큰도 함께 든다. 그래서 **같은 일을 API로 하는 것보다 토큰을 훨씬 많이 쓴다**(추측, 아래 근거).
- 권하는 길:
  - **메뉴 이름 검수 초안(약 500개)**: (가) 하위 에이전트, Haiku 5.5, effort **medium**. 일이 작아서(입력 10만 토큰 안팎) 한도 부담이 작다. 사람이 한 번 더 볼 초안이라 재현성 요구도 낮다.
  - **번역(1,379청크)**: (나) 또는 (다)의 **Batch API**로 돌리는 스크립트를 권한다. 모델은 Haiku 5.5 effort medium(키가 있을 때) 또는 이미 키가 있는 gpt-6-luna reasoning medium. 같은 입력·같은 지시로 다시 돌릴 수 있고, 결과가 파일로 남는다. (가)로 하면 에이전트 약 90개를 띄워야 해서 한도를 많이 쓰고, 지시문을 메인 에이전트가 매번 새로 써서 재현이 어렵다.
  - effort **high**는 처음부터 쓰지 않는다. 공식 안내는 Haiku 5.5에서 high를 "지식 작업, 긴 에이전트 일, **엄격한 지시 따르기**"에 쓰라고 한다. "사전에 있는 표기만 써라"는 엄격한 지시 따르기에 가깝다. 그러니 medium으로 50청크쯤 시험해 사전 표기 위반이 보이면 high로 올린다.
- **확인 필요**: Anthropic API 키가 있는지(없으면 (다)는 안 된다). 구독 요금제가 무엇인지(Pro/Max). 이 조사는 `.env`를 열지 않았다.

### 어림 비용(돈, API 기준)

가정(아래 "계산 가정"에 자세히): 원문 12만 9천 단어. Claude는 공식 환산(100만 토큰 ≈ 55만 5천 단어)으로 **1단어 ≈ 1.8토큰**, OpenAI는 요청대로 1단어 ≈ 1.3토큰. 한국어 출력 = 원문 토큰의 1.5-2배(근거 못 찾음, 가정). 생각 토큰(모델이 답 전에 혼자 생각하는 데 쓰는 토큰, 출력으로 청구) = 보이는 출력의 +50%(medium)·+100%(high)로 가정(공식 숫자 없음). 지시+사전 2천 토큰을 요청마다 반복, 요청은 청크 1개마다 1번(1,379번, 가장 비싼 쪽).

### 1. Claude Haiku 5.5 기본 정보

- [확인] 모델 ID `claude-haiku-5-5`, 2026-10-07 출시. 문맥(한 번에 넣을 수 있는 길이) 100만 토큰, 최대 출력 12만 8천 토큰(Batch에서 베타 헤더를 쓰면 30만). 신뢰할 수 있는 지식 마감과 학습 데이터 마감은 모두 2026년 6월. 생각은 adaptive(모델이 생각할지·얼마나 할지 스스로 정함), 기본 effort는 `medium`. 공식 설명은 "For high-volume, latency-sensitive tasks such as classification, extraction, and routing". https://platform.claude.com/docs/en/models/haiku-5-5/overview · https://platform.claude.com/docs/en/about-claude/models/overview
- [확인] 가격(백만 토큰당). **프롬프트가 10만 토큰 이하**일 때 입력 $0.10, 출력 $0.50, 5분 캐시 쓰기 $0.125, 1시간 캐시 쓰기 $0.20, 캐시 읽기 $0.01. 10만 토큰을 넘으면 입력 $0.50, 출력 $2.50(5배)이다. Batch는 입력 $0.05, 출력 $0.25. https://platform.claude.com/docs/en/about-claude/pricing
  - 이 프로젝트의 요청은 청크 하나가 수천 토큰이라 10만을 넘지 않는다. 요청 하나에 청크를 수십 개 몰아넣지 않는 한 싼 가격이 적용된다.
- [확인] 토크나이저(글을 토큰으로 자르는 방식). Haiku 4.5보다 같은 글이 약 30% 많은 토큰이 된다. 100만 토큰은 대략 55만 5천 단어다(→ 1단어 ≈ 1.8토큰). https://platform.claude.com/docs/en/models/haiku-5-5/whats-new-haiku-5-5 · 모델 개요 페이지 각주
- [확인] 발표 글은 "best suited to more narrowly scoped tasks"라고 쓰고, Sonnet 5.5·Opus 5.5가 복잡한 에이전트 코딩에는 더 낫다고 한다. https://www.anthropic.com/claude-haiku-5-5

### 2. effort 설정과 비용

- [확인] API 파라미터는 `output_config.effort`이고 값은 `low`·`medium`·`high`·`xhigh`·`max`다. Haiku 5.5는 다섯 개 모두 지원한다. 베타 헤더는 필요 없다. 기본값과 같은 `medium`을 보내는 것은 아무것도 안 보내는 것과 같다. https://platform.claude.com/docs/en/build-with-claude/effort
- [확인] effort는 생각뿐 아니라 **응답의 모든 토큰**(본문·도구 호출·생각)에 영향을 준다. 같은 문서다.
- [확인] Haiku 5.5 권장(위 문서와 https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-haiku-5-5):
  - `low`: 채팅, 짧은 도구 작업, 단순한 대량 요청
  - `medium`: 기본. 대부분의 일
  - `high`: "knowledge work, longer agent tasks, and **strict instruction following**"
  - `xhigh`·`max`: 평가에서 이득이 보일 때만. 그때는 Sonnet 5.5와도 견줘 보라고 한다
- [확인] 생각 토큰은 출력 토큰으로 청구된다. https://code.claude.com/docs/en/costs ("Thinking tokens are billed as output tokens")
- [확인] 공식 문서에 effort별 토큰 증가 숫자가 하나 있다. 긴 코딩 에이전트 프롬프트에서 low → medium으로 올리자 출력 토큰이 "more than doubled"였다. 번역에 쓴 숫자는 아니다. 출처는 Haiku 5.5 프롬프트 안내다.
- [확인] 프롬프트에 "바로 답하라"고 써도 생각을 멈추지 않았다고 한다. 생각을 줄이려면 effort를 낮추거나 `thinking: {"type": "disabled"}`(high 이하에서만)를 쓴다. 출처는 같은 안내다.
- **번역에 effort를 높이라는 공식 안내는 찾지 못했다.** 다국어 문서는 번역할 때 두 언어를 분명히 적으라고만 한다("Translate ... from German to Korean"). https://platform.claude.com/docs/en/build-with-claude/multilingual-support
- [확인] Claude Code 문서는 생각을 끌 수 없는 모델로 Opus 5.5, Sonnet 5.5, Haiku 5.5, Fable을 든다. https://code.claude.com/docs/en/costs
  - 이 문장은 위 API 문서(Haiku 5.5는 high 이하에서 disabled 가능)와 어긋난다. Claude Code 안에서는 끌 수 없다는 뜻으로 읽힌다(추측).

### 3. Batch API와 프롬프트 캐싱(Anthropic)

- [확인] Batch는 입력·출력 모두 50% 할인이다. "most batches finishing in less than 1 hour"이고, 24시간 안에 끝나지 않은 요청은 만료된다(청구 안 함). 결과는 29일 동안 받을 수 있다. 배치 하나에 요청 10만 개 또는 256MB까지. https://platform.claude.com/docs/en/build-with-claude/batch-processing
- [확인] 캐싱(같은 앞부분을 저장해 두고 싸게 다시 읽기)의 가격은 5분 쓰기가 입력의 1.25배, 1시간 쓰기가 2배, 읽기가 0.1배다. Haiku 5.5의 최소 길이는 **512토큰**이라 지시+사전 2천 토큰은 캐시할 수 있다. 512보다 짧으면 오류 없이 그냥 캐시가 안 된다. https://platform.claude.com/docs/en/build-with-claude/prompt-caching
- [확인] Batch와 캐싱 할인은 겹쳐 적용된다. 다만 Batch 안의 캐시 적중은 "best-effort"이고, 적중률은 보통 30-98%다. 공통 앞부분이 있으면 1시간 캐시를 쓰라고 권한다. Batch 문서다.

### 4. 한국어·다국어 품질 근거

- [확인] 공식 다국어 표(영어를 100%로 둔 MMLU 번역판 점수)에는 **Haiku 5.5가 없다**. 있는 모델은 Sonnet 4.5(한국어 96.7%)와 Haiku 4.5(한국어 93.3%)뿐이다. https://platform.claude.com/docs/en/build-with-claude/multilingual-support
  - 이 점수는 "한국어로 낸 시험 문제를 얼마나 맞히나"이지 번역 품질이 아니다.
- [확인] 모델 개요는 "All current models support ... multilingual capabilities"라는 일반 문장뿐이다.
- [확인] Haiku 5.5 발표 글의 벤치마크 표에는 다국어·번역 항목이 없다(GDPval, OSWorld, HLE, Terminal-Bench 등).
- 결론: **Haiku 5.5의 한국어·번역 품질을 보여 주는 공식 숫자는 없다.** 직접 50청크쯤 시험해야 한다.

### 5. 비교: OpenAI gpt-6-luna

- [확인] 가격(짧은 문맥, 백만 토큰당): 입력 $0.10, 캐시된 입력 $0.01, 30분 캐시 쓰기 $0.125, 출력 $0.50. Batch·Flex는 입력 $0.05, 출력 $0.25. 긴 문맥은 입력 $0.20, 출력 $0.75. https://developers.openai.com/api/docs/pricing · https://developers.openai.com/api/docs/models/gpt-6-luna
  - → **프로젝트 기록(HISTORY.md "입력 $0.10·출력 $0.50, 공식 확인 안 함")은 공식 가격과 같다.** `archive/research/04-모델-후보-조사.md`도 이미 같은 값을 공식 페이지로 확인해 두었다.
- [확인] 문맥 1,050,000토큰, 최대 출력 128,000토큰, 지식 마감 2026-05-18. 모델 페이지다.
- [확인] 생각 수준은 `reasoning.effort`(Chat Completions에서는 `reasoning_effort`)이고 값은 `none`·`low`·`medium`(기본)·`high`·`xhigh`·`max`다. 생각 토큰은 출력으로 청구된다. 모델 페이지와 https://developers.openai.com/api/docs/guides/reasoning
- [확인] Batch 50% 할인. 처리 기한·평균 시간은 이번에 OpenAI 문서에서 따로 확인하지 못했다.
- [확인] 다국어·번역에 대한 공식 숫자는 모델 페이지에서 찾지 못했다.
- 참고 [확인]: Haiku 5.5 발표 표에는 GPT-6 Luna 열이 있다. 예를 들어 GDPval-AA는 Haiku 5.5 1620, Luna 1437이다(Anthropic이 잰 값이고, 표의 열 순서는 페이지 모양에서 읽은 것이라 조금 불확실). 번역과는 관계가 먼 지표다.

### 6. Claude Code 하위 에이전트로 돌리기((가))

### 7. 계산 가정과 계산

- 원문 토큰: Claude는 129,000 × 1.8 ≈ 232,000 [계산, 공식 환산]이고, OpenAI는 129,000 × 1.3 ≈ 168,000 [가정, 요청 값]이다.
- 한국어 출력: 원문 토큰의 2배(위쪽 값)로 잡았다. Claude 464,000, OpenAI 336,000 [가정, 근거 못 찾음].
- 생각 토큰: 보이는 출력의 +50%(medium), +100%(high)로 잡았다 [가정].
- 반복 지시+사전: 2,000 × 1,379 = 2,758,000 토큰 [가정].
- Haiku medium, 일반 호출: 입력 (232k + 2,758k) × $0.10 = $0.30, 출력 696k × $0.50 = $0.35, 합 $0.65. Batch는 절반인 $0.33. Batch+캐싱: 원문 232k × $0.05 = $0.012, 캐시 읽기 2,758k × $0.005 = $0.014, 출력 696k × $0.25 = $0.17, 합 약 $0.19. 캐시 쓰기는 몇 번뿐이라 뺐다. 캐시 적중률을 100%로 본 값이다. 공식 범위 30-98%라면 $0.19-0.26이다.
- Haiku high: 출력 928k로 바꿔 같은 방식으로 계산했다.
- luna: 입력 168k + 2,758k, 출력 504k(medium)·672k(high)로 같은 방식으로 계산했다. 캐시 읽기는 Batch 가격 $0.005를 썼다. OpenAI 토크나이저로 지시+사전이 몇 토큰인지는 따로 재지 않았다.
- 청크를 5개씩 묶어 요청하면 반복분이 1/5로 줄어 일반 호출 기준 약 $0.25-0.3 낮아진다. 어느 경우든 $1을 넘지 않는다.
- 메뉴 검수: 항목당 입력 150토큰 × 500 = 75k, 지시 2k × 20 = 40k, 출력 항목당 50토큰 × 500 = 25k와 생각 토큰으로 계산했다.
