# 16: 검 연습 과정 파일 초안

Blocked by: 15

근거: 명세 "연습 과정 파일", 닫힌 티켓 05·13·14

## 만들 것

검 연습 과정 YAML 초안(AI 초안)을 쓴다. 기본 장면에서 기본 정육면체를 칼날 시작으로 쓰고 glTF 내보내기로 끝난다. 공통 준비를 "먼저 할 것"으로 가리킨다. 사용자가 따라 하며 고치는 검수는 32번에서 한다.

## 완료 조건

- [ ] 15번 기본 검사를 통과한다.
- [ ] 단계마다 이름표·이름·목표 모양·쉬운 설명(2-3문장)·조작 목록(영어 메뉴 경로 + 단축키)·먼저 볼 설명서 소제목 1-3개가 있다.
- [ ] 알아챌 수 있는 단계에는 정해진 검사 종류로만 끝난 조건을 적는다. 치수는 비율 위주의 참고값이다.
- [ ] 설명서 문장을 그대로 옮기지 않는다.
