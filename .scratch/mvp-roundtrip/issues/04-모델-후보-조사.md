# 답변·임베딩 모델 후보

Type: research
Status: resolved

## Question

답변 모델과 임베딩 모델 후보의 속도·가격·한국어 품질은 어떤가?

- gpt-6-luna 생각 수준 low와 medium: 응답 시간, 가격, 품질 차이(이전 프로젝트는 답변 medium, 리랭커 low)
- 한국어 질문으로 영어 문서를 찾는 다국어 임베딩 후보(text-embedding-3-large 포함)와 설명서 전체 임베딩 비용 추정
- 비교 대상 GPT(웹 채팅)는 어떤 모델인가

## Answer

자세한 내용: 브랜치 `research/04-models`의 `.scratch/mvp-roundtrip/research/04-모델-후보-조사.md` (커밋 2d50348)

- gpt-6-luna: 입력 $0.10 / 출력 $0.50(100만 토큰당). low와 medium의 속도 차이는 공식 숫자 없음
- 이전 프로젝트 실측: 답변 호출(medium) 2.6-2.8초, 질문 하나 전체 18-20초. 오래 걸린 것은 리랭커(6-13.5초)·근거 대조(8-9초) 같은 추가 호출
- 임베딩: OpenAI 최신은 여전히 text-embedding-3-large($0.13)/small($0.02). 설명서 전체 임베딩 약 $0.2-0.7 추정. 한국어 질문 → 영어 문서는 bge-m3(내 PC에서 돌리는 모델)가 더 높다는 저자 보고
- 비교 대상 ChatGPT 기본 모델은 바뀌는 중이고 공식 문서끼리 어긋남. 비교할 때 화면의 모델 이름을 매번 기록
- 이전 프로젝트의 '로컬 모델 제외'는 답변 모델을 고를 때의 결정(작업기록.md:1417). 임베딩에는 정해진 것 없음
