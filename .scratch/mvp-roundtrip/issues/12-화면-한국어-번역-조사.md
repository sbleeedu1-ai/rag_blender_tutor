# Blender 5.2 화면 한국어 번역 범위와 메뉴 이름 대응 방법

Type: research
Status: open

## Question

Blender 5.2 화면(UI)을 한국어로 바꿨을 때 메뉴 이름이 얼마나 번역되어 있고, 답에 쓰는 영어 메뉴 이름을 화면에 보이는 한국어 이름으로 어떻게 바꿀 수 있는가?

- 화면 번역 파일(사전)이 어디 있는가(설치본 안, 공개 저장소), 한국어 번역 비율
- 연습 과정(검·방패)에 나오는 메뉴·기능 이름의 한국어 번역 예시와 빠진 것
- 애드온이 화면 언어 설정을 읽는 방법, Blender 안의 번역 기능으로 영어 이름을 지금 화면 언어로 바꿀 수 있는가(같은 영어 문구가 뜻에 따라 다르게 번역되는 경우 포함)
- 화면만 번역하고 도움말 문구는 영어로 두는 식의 부분 번역 설정이 있는가
