# Blender 5.2 화면 한국어 번역 범위와 메뉴 이름 대응 방법

Type: research
Status: resolved

## Question

Blender 5.2 화면(UI)을 한국어로 바꿨을 때 메뉴 이름이 얼마나 번역되어 있고, 답에 쓰는 영어 메뉴 이름을 화면에 보이는 한국어 이름으로 어떻게 바꿀 수 있는가?

- 화면 번역 파일(사전)이 어디 있는가(설치본 안, 공개 저장소), 한국어 번역 비율
- 연습 과정(검·방패)에 나오는 메뉴·기능 이름의 한국어 번역 예시와 빠진 것
- 애드온이 화면 언어 설정을 읽는 방법, Blender 안의 번역 기능으로 영어 이름을 지금 화면 언어로 바꿀 수 있는가(같은 영어 문구가 뜻에 따라 다르게 번역되는 경우 포함)
- 화면만 번역하고 도움말 문구는 영어로 두는 식의 부분 번역 설정이 있는가

## Answer

자세한 내용: 브랜치 `research/12-ui-korean`의 `.scratch/mvp-roundtrip/research/12-화면-한국어-번역-조사.md` (커밋 734adb5)

- 화면 번역 사전은 설치본 `5.2/datafiles/locale/ko/LC_MESSAGES/blender.mo`, 원본은 Blender 본 저장소 `blender-v5.2-release`의 `locale/po/ko.po`
- 한국어 화면 번역률 약 93%(직접 센 값 39,341개 중 36,776개). 설명서 번역(1.1%)과 별개
- 연습 과정 메뉴는 거의 번역됨. 예외: 병합 메뉴의 "At Center"는 한국어 화면에서도 영어(이 PC의 Blender 5.2.2로 확인)
- 같은 영어 문구도 문맥(msgctxt)마다 번역이 다르다(Edit Mode: "에디트 모드"/"편집 모드", Apply: "적용"/"신청하기" 등)
- 애드온: 실제 화면 언어는 `bpy.app.translations.locale`로 읽는다(설정값이 'DEFAULT'일 수 있음). `pgettext_iface(영어, 문맥)`로 화면과 같은 한국어를 얻고, 사용자의 번역 체크도 따른다. 문맥을 정확히 넘겨야 한다
- 부분 번역 체크 4개(도움말·인터페이스·보고서·새로운 데이터). 빠른 설정 창에서 한국어를 고르면 넷 다 켜진 채로 시작 → 새로 만든 물체 이름도 한국어일 수 있다
