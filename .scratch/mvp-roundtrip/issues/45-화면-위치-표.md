# 45: 화면 위치 표로 "어디 있어요"에 답하기

Blocked by: 35
Status: needs-triage

근거: 티켓 32 다시 검수(HISTORY [141]), 명세 "답"

## 할 것

설명서는 "3D Viewport header", "Viewport Shading popover"처럼 화면 부분의 이름만 쓰고 화면 어디인지는 거의 말하지 않는다. 그래서 답이 맞아도 처음 쓰는 사람이 찾아가지 못한다.
자주 나오는 화면 부분(헤더, 사이드바, 툴바, 속성 창의 탭들, 셰이딩 버튼·팝오버, 아웃라이너 등)의 위치를 Blender 5.2 기본 화면에서 확인해 짧은 표로 만들고, 답 모델이 이 표로 "3D 화면 오른쪽 위, 동그라미 네 개 옆 ▼"처럼 위치를 말하게 한다.

## 완료 조건

- [ ] 표에 넣을 화면 부분을 고르고, 위치를 Blender 기본 화면(한국어·영어)에서 확인한다. 표 글은 우리 말로 쓴다.
- [ ] 답 엔진이 표를 쓴다(전부 늘 넘길지, 청크·질문에 나온 것만 붙일지는 TERMS처럼 비용을 보고 정한다).
- [ ] 35의 개발 문항에 아래 예를 넣고 고치기 전후를 비교한다.

## 예 (2026-11-02 다시 검수에서 실제로 물은 것)

- "엑스레이 모드 뭐였지?" → 답: Alt-Z, "뷰포트 셰이딩(Viewport Shading) 팝오버의 X-Ray 옵션". 내용은 맞음(근거 Introduction > Header Region > Display & Shading).
- 이어서 "뷰포트 셰이딩 팝오버는 어딨는데?" → 답: "3D 뷰포트 헤더에서 뷰포트 셰이딩 옆의 드롭다운 버튼". 사용자 "설명서 대로 한거는 맞을거 같은데 하.. 뭔가 찾아가기 어렵긴하다 저런 설명으로는".
- 빠진 것: 화면 오른쪽 위에 X-Ray 켜고 끄는 버튼이 따로 있다(같은 근거 청크의 "Toggle X-Ray"). 위치를 말했다면 바로 찾을 수 있었다.
