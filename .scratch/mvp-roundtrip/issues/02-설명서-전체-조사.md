# 5.2 설명서 전체의 언어·구조·수집 방법

Type: research
Status: resolved

## Question

Blender 5.2 공식 설명서 전체를 검색 대상으로 모으려면 무엇을 알아야 하는가?

- 전체 쪽수·문서 수, 목차만 있는 쪽 수(제안서의 4.5 숫자 2,072개 → 목차 제외 1,734개는 Claude 채팅이 낸 참고치로, 확인할 코드가 없다)
- 공식 한국어 번역이 있는가, 있다면 범위와 최신 정도
- 내려받는 방법(HTML 묶음, 소스 저장소 등)과 라이선스 표시 방법
- 그림이 들어간 문서 비율, 그림 설명(alt 등)이 있는가
- 수집 코드는 없다(제안서의 "준비한 코드"는 Claude 채팅이 스스로 돌린 것). MVP 명세에서 새로 만든다

## Answer

자세한 내용: 브랜치 `research/02-manual`의 `.scratch/mvp-roundtrip/research/02-설명서-전체-조사.md` (커밋 9220c08)

- 5.2 설명서는 2,358쪽, 목차만 있는 쪽 297개를 빼면 본문 2,061쪽. 같은 방법으로 4.5를 세면 2,072쪽이라 제안서 숫자와 같다
- 공식 한국어판은 주소만 있고 번역 완료 1.1%. 사실상 영어 원문만 있다
- 수집은 공식 HTML 묶음(zip 360MB)이 맞다. 근거 링크는 `/en/5.2/<경로>.html#<앵커>`로 고정한다(HTML 안 주소는 /en/latest/)
- 라이선스 표시: "Blender Documentation Team" + 설명서 링크(copyright 쪽 예시 문구)
- 본문 쪽의 71.4%에 그림(3,782개). 캡션 72.4%, 쓸 만한 alt 19.3%
- 공식 '초보자 범위'는 없다(시작하기 분야 16쪽). 제안서의 '약 300쪽'은 확인 불가
