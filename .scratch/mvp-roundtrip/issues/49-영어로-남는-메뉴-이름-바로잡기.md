# 49: 한국어 화면 사용자가 답 속 메뉴 이름을 화면에서 바로 찾도록, 영어로 남는 이름을 화면 글자로 바꾼다

Status: ready-for-human

근거: HISTORY [343] 1번(사용자 "B ㅇㅇ 이건 확정으로 가고"), [344]-[347]. 채점에서 한국어 화면인데 이름을 영어로만 쓴 답은 부분이다(`docs/agents/grading.md` 37줄, [310]). 채점한 답 378개 중 이 까닭으로 깎인 답 66개, 그중 지금 사전으로 이름이 다 바뀌는 답은 20개뿐([344]).

## 지금

- 답 모델이 `[[Add > Mesh]]`로 감싼 이름만 `answer_engine._MenuMarks` → `menu_names.screen_path`가 사전(`data/menu_names/menu_names.json`, 설명서의 메뉴·옵션 표시에서 뽑은 7,699개)으로 바꾼다. 사전에 없는 이름(Origins 등)은 감싸도 영어로 남는다.
- 감싸지 않은 영어 이름("지금 Bevel 모디파이어는 Segments가 1")은 손대지 않는다.
- 모델이 스스로 지은 한국어를 붙인 이름("면(Face)", 화면은 "페이스")도 그대로다.

## 할 것([347])

1. 넓힌 이름 목록: 10-27 번역 때 정한 규칙([68] "A+B", `translate.screen_words`)처럼 사전에 없는 이름은 ko.po에서 번역이 하나뿐인 것을 더한다. 더해서 fr.po로 번역이 빠진 문맥(화면이 영어)이 있는 이름은 뺀다. 질문 찾기 표(`_question_index`)에는 섞지 않는다.
2. 감싼 이름: 사전에 없으면 넓힌 목록에서 찾는다. 말줄임표 꼴(Zoom Region → Zoom Region...)도 찾는다.
3. 감싸지 않은 맨 영어: 한국어 화면일 때 대문자로 시작하는 영어 덩이를 사전·넓힌 목록에서 긴 이름부터 맞춰 "한국어(영어)"로. 그대로 두는 것: 단축키(뒤에 "키"가 오거나 +로 이은 것, 한 글자), 백틱 속 코드, 작업 상태의 물체 이름, 프로그램 이름(Blender), "설명서의 …" 인용, 대문자만으로 된 낱말, 못 맞춘 낱말이 남는 덩이(Primary Bone Axis). 질문에 영어로 쓴 이름은 [311]대로 "영어(한국어)".
4. 화면과 다른 한국어가 붙은 괄호: "면(Face)" → 괄호 속에 화면 글자를 넣는다("면(페이스, Face)"). "Scale(크기 조절)" → "스케일(Scale, 크기 조절)". (처음엔 괄호 바로 앞 한 낱말을 바꾸려 했으나, 저장된 답을 읽으니 앞 글이 설명·동사일 때가 많아 "그 면들을 녹여(Dissolve)" → "그 면들을 디졸브(Dissolve)"처럼 문장이 깨져 바꿈, HISTORY [348])
5. 답이 흐르는 중이라 영어 덩이·괄호가 끝날 때까지만 붙잡는다.

## Comments

- 2026-11-16 완료 조건 밖에 더한 것:
  - `screen_prose(..., changed=)`: 바꾼 자리 (원래, 바뀐) 목록을 받는 인자. 저장된 답 검증(`돌리기.py`)에 씀.
  - `python -m blender_tutor.menu_names extra <ko.po> <fr.po> <사전 폴더>`: 사전 전체를 다시 만들지 않고 넓힌 목록만 만드는 명령(설명서 HTML 없이 돌리려고).
  - `OBJECT_DEFAULTS`(Cube·Plane·Camera 등 기본 물체 이름은 메뉴 경로 밖이면 안 바꿈): 저장된 답 Q11 "대상은 큐브(Cube)"로 고르지 않은 물체 이름이 바뀌는 것을 찾아서.
  - `PLACE_DEPENDENT`(Edge)와 경로 열쇠가 있는 이름(Bisect·Normal 등)은 감싸지 않은 글에서 안 바꿈: "엣지(Edge) 메뉴"(메뉴는 에지, [80]).
