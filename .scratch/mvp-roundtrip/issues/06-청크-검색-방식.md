# 청크·검색 방식

Type: grilling
Status: open
Blocked by: 02, 04, 05, 12

## Question

설명서 전체 원문과 연습 과정 + 초보자 범위(번역·쉬운 말 풀이)를 청크에 어떻게 담고, 무엇으로 검색하며, 일부를 어떻게 먼저 보는가? 초보자 범위는 어떤 기준으로 고르고(AI 분류의 근거), 초반 검수는 어떻게 하는가?

## 조사에서 넘어온 것

- 공식 한국어 번역이 사실상 없음 → 한국어 질문을 영어 원문과 맞추는 방법을 먼저 정한다(다국어 임베딩, 질문을 영어로 바꿔 검색, 일부만 한국어 번역 청크)
- 임베딩 후보: text-embedding-3-large / bge-m3(내 PC에서 실행, 쓸지 결정 필요)
- 청크는 소제목 단위 + `/en/5.2/...#앵커` 링크가 유력(쪽 길이 중간값 204단어, 최대 6,568단어)
- 설명서 기여자용 contribute 분야 26쪽을 검색에서 뺄지
- 공식 초보자 범위가 없으므로 초보자 분류 기준을 새로 정해야 함
- 강의실 PC(i7-4770, GTX 950 2GB, 16GB)는 Blender 5.x 최소 사양선. bge-m3를 이 PC에서 돌리면 GPU 메모리가 부족해 CPU로 돌아가므로, 전체 임베딩과 질문당 시간 부담을 함께 따진다(2026-10-19 사용자 사양 확인)
- (화면 한국어 번역 조사) 한국어 화면 사용자는 질문에 한국어 메뉴 이름("배열", "베벨")을 쓴다. 화면 번역 사전(ko.po)으로 영어 메뉴 이름으로 거꾸로 바꿔 검색에 쓸 수 있다. 같은 한국어가 여러 영어에 대응하는 경우가 있다
