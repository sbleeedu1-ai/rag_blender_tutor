# 22: 답 엔진 — 검색어 만들기와 덧붙이기

Blocked by: 15, 20, 21
Status: ready-for-agent

근거: 명세 "답 엔진"의 검색어 만들기·먼저 보기·비슷한 연습 과정

## 완료 조건

- [ ] 검색어 = 현재 질문 + 직전 질문 + 현재 단계 이름과 연결 소제목 + 방금 실행한 조작 이름(추가 호출 없음).
- [ ] 질문 속 한국어 메뉴 이름에 영어를 덧붙인다(여러 개면 모두).
- [ ] 현재 단계의 먼저 볼 소제목(최대 2-3개)을 검색 상위 위에 덧붙인다(대신하지 않음).
- [ ] 50단어 미만 청크는 같은 부모의 형제 소제목을 약 400단어까지 함께 넘긴다(링크는 찾은 소제목).
- [ ] 연습 과정을 진행하지 않을 때만 비슷한 연습 과정 상위 3개를 붙인다.
- [ ] 답변 모델에는 연습 과정 파일 전체가 아니라 지금 단계 내용만 넘긴다.

## Comments

- 2026-10-20 Claude(티켓 20에서): 한국어 → 영어 조회는 `MenuNames.english_for(한국어)`(띄어쓰기 무시, 여러 개면 모두). 질문 글에서 한국어 블렌더 표기를 찾아내는 일은 이 티켓 몫
  - 화면 글자와 조금 다르게 쓰면 못 찾는다(예: 화면 "위치를 복사", 사용자 "위치 복사")
  - 검수 전인 "제목에서만 뽑은 이름"(옵션 → Options, 사용법 → Usage 등)도 돌려준다. 검색어에 영어 낱말이 하나 더 붙는 정도라 해는 작다고 봄. 쓸지 거를지 여기서 정한다(`MenuName.sources`로 가를 수 있음)
