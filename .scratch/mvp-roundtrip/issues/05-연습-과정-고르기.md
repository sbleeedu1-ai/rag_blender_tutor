# 연습 과정 고르기

Type: grilling
Status: resolved
Blocked by: 03

## Question

MVP의 연습 과정(목표 아이템과 단계 목록)을 무엇으로 하는가?

## Answer

2026-10-19 사용자와 질문 라운드(Q1-Q16)로 정함. 근거 자료: 강좌 대조 조사(`research/03-course` 브랜치).

| 항목 | 결정 |
|---|---|
| 아이템 | 검과 방패 둘 다. 검을 먼저 완성(초안 → 사용자가 직접 따라 하기 → 고치기), 그다음 방패. 버전 차이(Array 등)는 평가 질문에서도 다룬다 |
| 끝 | glTF 파일로 내보내기. 게임에 불러오기는 범위 밖 |
| 시작 | 빠른 설정 창을 닫은 뒤의 기본 장면. 1단계는 공통 준비(화면 돌리기·확대·이동, 화면 언어 확인). 기본 정육면체를 칼날의 시작으로 쓴다 |
| 구조 | 구간 > 단계 > 조작. 진행 기록과 완료 판정은 단계 단위, 조작은 안내만 |
| 단계 크기 | 눈으로 확인할 수 있는 중간 결과 하나 = 단계 하나 |
| 치수 | 목표 모양을 말로 적고 치수는 참고로만. 엄격하게 따지지 않는다 |
| 검수 | AI가 5.2 설명서 근거로 초안 → 사용자가 Blender 5.2에서 처음부터 끝까지 따라 하며 막힌 곳 기록(막힌 곳은 평가 질문 후보). 명세 단계의 할 일 |
| 맞는 아이템이 없을 때 | 가장 비슷한 연습 과정을 권하고, 원하면 연습 과정 없이 자유 질문으로 계속 |
| 연습 과정 밖 질문·건너뛰기 | 둘 다 허용. 자유 질문은 설명서 전체로 답하고 현재 단계로 돌아온다. 원하는 단계로 건너뛸 수 있다 |
| 다시 켰을 때 | 저장 파일로 이어 하면 서버가 마지막 단계를 기억해 이어 할지 묻는다. 새 파일이면 1단계부터 |
| 화면 언어 | 영어가 기본, 한국어 화면도 MVP에서 지원. 한국어 화면이면 화면에 보이는 이름을 먼저 쓰고 영어를 괄호로("추가(Add) > 메시(Mesh)"). 번역 없는 메뉴는 영어 그대로 |

사용자 말: "둘 다 하는게 맞아보입니다. A / B", "시간이 걸려도 역시 해내야 하는게 맞아보입니다", "치수는 참고로만, 애초에 초보자인데 그런걸 엄격하게 적용하면 말이 안 되죠", "초보자용이면 한국어로 설정할 가능성도 높아보입니다 ... 한국어 지원도 필요해보입니다"
