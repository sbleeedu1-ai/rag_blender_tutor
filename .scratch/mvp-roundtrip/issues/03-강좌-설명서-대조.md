# 4.5 강좌와 5.2 설명서 대조

Type: research
Status: resolved

## Question

Blender Studio Fundamentals 4.5 강좌의 단계는 5.2에서 그대로인가, 바뀌었나, 없어졌나? 초보자가 아이템 하나를 만드는 연습 과정 후보는 무엇인가?

- 강좌 단계별로 그대로·바뀜·없어짐과 해당 5.2 설명서 쪽
- 5.2용 공식 입문 강좌가 새로 나왔는가
- 연습 과정 후보 2-3개(예: 단순한 검)와 각각 필요한 단계·기능

## Answer

자세한 내용: 브랜치 `research/03-course`의 `.scratch/mvp-roundtrip/research/03-강좌-설명서-대조.md` (커밋 b0db9f2)

- 5.x용 공식 입문 강좌는 없다. Fundamentals는 4.5 기준(5.2용으로는 애니메이션 장만 추가)
- 아이템 만들기에 필요한 장은 대부분 그대로. 크게 바뀐 것은 Array 모디파이어(5.0 새로 만듦, 옛것은 Array (Legacy))
- 작게 바뀐 것: 메뉴 열림 방식, 숫자 키 컬렉션 숨기기, UV 동기 선택 기본값, 재질 Use Nodes 버튼 없어짐, Merge by Distance 옵션, LoopTools 일부 기본 기능화
- 연습 과정 후보: A 단순한 검(쉬움), B 둥근 방패(보통, Solidify·새 Array), C 물약병(보통, To Circle·유리 재질)
- 주의: '그대로'는 문서 판단이고 Blender에서 직접 눌러 보지 않음. 강좌 라이선스(CC BY 4.0) 문구는 강좌 쪽에서 확인 못 함
