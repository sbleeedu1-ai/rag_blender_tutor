# 19: 자료 준비 — 설명서 HTML을 청크로

Blocked by: 없음(바로 시작 가능)
Status: ready-for-agent

근거: 명세 "자료 준비", User Stories 58-61, 시험 경계 ④

## 만들 것

공식 5.2 설명서 HTML 묶음을 소제목 단위 청크로 자르는 한 번 돌리는 프로그램. 비용이 들지 않는다.

## 완료 조건

- [ ] 직접 쓴 작은 HTML 조각(설명서 원문 아님)으로 청크 경계·경로·앵커·위계 메타데이터·그림 표시(`[그림: 캡션]`/`[그림]`)·400단어 넘는 소제목 나누기·제목뿐인 소제목 처리를 테스트한다.
- [ ] 영상만·그림만 있는 소제목은 앞 청크 메타데이터로, contribute 쪽은 제외, 목차만 있는 쪽은 버린다.
- [ ] `data/`에 묶음이 있으면 전체를 돌려 청크 수(약 9,100개 예상)를 보고한다. 결과는 `data/`에 두고 커밋하지 않는다.
