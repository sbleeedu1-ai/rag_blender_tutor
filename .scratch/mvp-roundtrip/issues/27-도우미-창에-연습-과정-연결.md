# 27: 도우미 창에 연습 과정 연결

Blocked by: 16, 18, 26
Status: ready-for-agent

근거: 명세 "진행 관리", User Stories 34-50

## 완료 조건

- [ ] 연습 과정 고르기(없으면 비슷한 것 권함, 자유 질문으로 계속 가능)와 바꾸기 확인.
- [ ] 단계마다 목표 모양·쉬운 설명·조작 목록 표시, "n단계"는 파일 순서.
- [ ] 진행 관리가 돌려준 물음을 창 안에만 [네] [아니요]로 띄우고 거둔다. 다음 단계·건너뛰기·뒤로 버튼.
- [ ] 파일을 다시 열면 이어 하기 물음.
- [ ] 진행 관리(`ProgressManager`)를 Blender 창 번호마다 하나씩 둔다. Blender 둘을 오가도 진행을 비우거나 다시 묻지 않고, 각 창의 진행은 그 창 파일의 기록에만 남는다. 기록 폴더는 함께 쓴다.
- [ ] 자유 질문 뒤 현재 단계로 돌아온다.

## Comments

- 2026-10-20 Claude(티켓 18에서 넘김): 창은 `blender_tutor/progress_record.py`의 `ProgressManager`에 사건을 넘기고 돌려받은 것(`Ask`·`Withdraw`·`AskResume`·`AskChangeCourse`·`Notice`)을 띄운다. 연습 과정은 `progress.load_course`로 읽는다. 기록 폴더는 사용자 설정 폴더(`%APPDATA%\blender_tutor\progress` 권장)를 이때 정해 넘긴다(티켓 18에서는 쓰는 곳이 없어 넣지 않음). `ProgressManager`는 파일 하나의 진행만 들고 있다. HISTORY [30]
- 2026-10-20 Claude(티켓 18에서 넘김): 진행 관리를 하나만 두면 Blender 둘을 오갈 때 창을 바꿔도 "파일 열림"이 오지 않는다. 그래서 마지막으로 연 파일의 진행에 다른 창의 버튼이 적힌다. 창 번호마다 하나씩 두기로 확정해 완료 조건에 넣었다. 같은 기록 폴더를 함께 써도 섞이지 않는 것은 `tests/test_progress_record.py`의 창마다 따로 두는 테스트로 확인했다. 같은 파일을 두 창에서 열면 나중에 바뀐 쪽이 덮어쓴다(명세대로). HISTORY [31]
- 2026-10-22 Claude(티켓 22에서 넘김): 창은 답 엔진에 지금 단계를 넘긴다: `AnswerEngine.answer(질문, 작업 상태, 최근 대화, ProgressManager.step)`. 연습 과정을 진행하지 않으면 `None`이고, 그때만 비슷한 연습 과정 3개가 붙는다. 엔진을 만들 때 `menu_names=MenuNames.load(data/menu_names/menu_names.json)`, `courses=`(load_course로 읽은 것), `course_vectors=`(티켓 31에서 만든 벡터, 개수가 같아야 함)를 넘긴다. 작업 상태의 `recent_operators`(방금 조작 3개)가 검색어에 붙는다(칸 이름은 티켓 25에서 확정).
