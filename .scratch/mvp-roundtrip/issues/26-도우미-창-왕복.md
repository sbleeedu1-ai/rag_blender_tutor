# 26: 도우미 창 왕복

Blocked by: 21, 25, 화면 방식(QML / 위젯) 시제품 비교
Status: ready-for-agent

근거: 명세 "도우미 창", ADR-0001, User Stories 3-12·18-21·31, 조사 `archive/research/도우미-창-UI-도구-조사.md`, HISTORY [17]

## 만들 것

F10으로 도우미 창이 앞으로 나와 한글로 질문하고, 답 엔진의 답이 흘러나오듯 보인다.

## 완료 조건

- [ ] ADR-0001 창 동작: 작게·정해진 자리, Esc로 그 Blender 복귀, Blender가 앞일 때만 맨 위, 최소화 연동, 직접 내리면 F10까지 내린 채, 줄여도 입력칸과 최근 답 일부 보임.
- [ ] Enter 한 번에 보내고, 답은 스트리밍, 근거는 끝에 한꺼번에, 근거 링크를 누르면 설명서가 열린다.
- [ ] 질문은 마지막으로 앞에 있던 Blender의 상태로 보낸다. 최근 대화 3쌍을 들고 창이 꺼지면 사라진다.
- [ ] 답을 기다리는 동안 Blender가 멈추지 않는다. 오류·시간 초과는 짧은 문구.
- [ ] 사용자가 강의실 PC에서 한글 입력·F10 → 입력 가능 시간·창 동작을 눈으로 확인한다.
- [ ] 화면 도구는 PySide6. QML을 쓸지 파이썬 위젯만 쓸지는 시제품 비교 뒤 정한다.
- [ ] 모양: 테두리·제목 표시줄 없음, 어두운 반투명 판(진짜 흐림은 끌 수 있는 선택 기능), 둥근 모서리, 답은 크고 굵은 흰 글씨·질문은 작은 회색, 근거는 반투명 둥근 카드, 아래 알약 모양 입력칸. Apple·Siri 이름·로고는 쓰지 않는다.
- [ ] 버튼은 오른쪽 위 `X`(숨기기) 하나, 마우스를 올렸을 때 보인다. 가장자리를 끌어 크기를 바꿀 수 있다.
- [ ] 작업 표시줄과 Alt+Tab에 나오지 않고 트레이 아이콘만 둔다. 왼쪽 클릭 = 보이기(숨기지 않음), 오른쪽 메뉴 = 보이기 / 끝내기. 끝낸 뒤 F10을 누르면 애드온이 다시 켠다.
- [ ] 보이지 않는 Blender만 있으면(모두 최소화) 트레이 보이기를 막고, 아이콘 안내에 "Blender를 먼저 열어 주세요". Blender가 하나라도 보이면 F10과 똑같이 부른다(그 뒤 다른 프로그램을 누르면 ADR-0001대로 그 뒤로).
- [ ] 앞 프로그램이 작업 표시줄·트레이일 때는 창을 그대로 둔다(트레이 클릭 때 깜빡임 방지).
- [ ] 설치 안내에 "트레이 아이콘을 ^ 밖으로 꺼내 두세요" 한 줄(프로그램이 바꿀 수 없음).
