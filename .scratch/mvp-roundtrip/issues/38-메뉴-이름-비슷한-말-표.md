# 38: 메뉴 이름 비슷한 말 표

Blocked by: 30
Status: needs-triage

근거: 티켓 22 Comments(알려진 한계), 명세 "답 엔진"의 검색어 만들기

## 만들 것

사용자가 화면 글자와 다른 낱말로 물어도 영어 메뉴 이름을 검색어에 덧붙이기 위해, 초보자 범위 안의 작은 비슷한 말 표(예: 꼭짓점 → 버텍스, 모서리 → 엣지)를 만든다.

## 완료 조건

- [ ] 초보자 범위(티켓 30) 안에서 화면 글자와 사람들이 흔히 쓰는 말이 다른 것을 모은다. 연습 과정 파일(검·방패)이 쓰는 말부터.
- [ ] 답 엔진의 질문 속 메뉴 이름 찾기가 이 표도 본다.
- [ ] 개발 평가에서 표를 켬/끔으로 견줘 실제로 도움이 되는지 본다. 도움이 없으면 넣지 않는다.
