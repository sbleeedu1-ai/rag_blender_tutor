# 애드온 ↔ 서버 주고받는 형식

Type: grilling
Status: resolved
Blocked by: 01, 12

## Question

애드온과 서버가 주고받는 질문 + 작업 상태 → 답 + 근거의 형식은 무엇인가? MVP가 쓰는 칸만 둔다.

## 다른 티켓에서 넘어온 것

- 작업 상태에 화면 언어가 들어간다(연습 과정 고르기). 한국어 화면이면 메뉴 이름을 바꿔 보여 줘야 하는데, 서버가 바꿀지 애드온이 Blender 번역 기능으로 바꿀지 정한다
- (화면 한국어 번역 조사) 메뉴 이름을 바꾸려면 "메뉴 경로 → 문맥" 정보를 누군가 들고 있어야 한다. (a) 서버가 사전으로 변환: Blender 없이 서버를 시험할 수 있고, 사용자가 쓴 한국어 메뉴 이름을 영어로 거꾸로 바꿔 검색에도 쓴다. (b) 서버는 영어 원문+문맥을 표시해 보내고 애드온이 `pgettext_iface`로 변환: 화면 글자와 정확히 같고 사용자 번역 설정을 따른다. 둘 중 무엇으로 할지
- (같은 조사) 선택 물체 이름이 한국어일 수 있다(새 데이터 이름 번역이 켜진 경우)
- (애드온 왕복 시제품) 주고받는 쪽이 셋이 됐다: 애드온(단축키·작업 상태) → 도우미 창(입력·표시) → 서버. 도우미 창이 서버와 한 프로그램인지, 작업 상태를 애드온이 서버에 바로 보내는지 창을 거치는지 정한다
- (같은 시제품) 도우미 창은 Blender 밖이라 `pgettext_iface`를 직접 못 쓴다. 메뉴 이름 바꾸기의 (b)안은 애드온에 번역을 맡기는 왕복이 하나 더 생긴다. (a)안(서버 사전)과 다시 견준다
- (같은 시제품) 애드온은 창을 앞으로 부를 때 Blender 창 번호(Esc로 돌아올 곳)와 `AllowSetForegroundWindow` 허락을 함께 처리한다. 시제품의 F10 → 입력 가능 108-124ms
- (같은 시제품, 사용자 결정) 실행은 "애드온이 Blender를 켤 때 도우미 창·서버를 켜고 닫을 때 끈다". 남은 질문: Blender 프로그램이 둘 이상 켜졌을 때(파일을 또 두 번 눌러 연 경우) 도우미·서버를 하나로 같이 쓸지, 도우미가 어느 Blender를 따라갈지
- (그림이 중요한 설명의 처리) 답의 근거마다 "그림 있음"·"영상 있음" 표시와 영상 링크가 붙는다. 도우미 창은 그림을 직접 띄우지 않고 근거 링크로 웹사이트를 연다

## Answer

2026-10-19 사용자와 질문 라운드(Q1-Q6, 두 번)로 정함. 근거: 시제품(`prototype/01-addon-roundtrip`)은 애드온이 F10 때 작업 상태를 도우미 창에 HTTP(`127.0.0.1:8766`)로 보내고, 도우미 창(Python tkinter)이 같은 프로그램 안에서 가짜 답을 만든다.

| 항목 | 결정 |
|---|---|
| 구성 | 도우미 창과 답 엔진(검색 + 답 생성)은 **한 프로그램**. 형식의 경계는 "창 ↔ 답 엔진": 답 엔진은 "질문 + 작업 상태 → 답 + 근거"만 받아 Blender·창 없이 시험·평가할 수 있다. 나중에 나눌 때는 그 사이에 HTTP 한 겹만 넣는다 |
| 작업 상태 보내기 | 애드온 → 도우미 창(HTTP, 내 PC 안). F10 때 보내고, 0.5초마다 확인해 **바뀌었을 때만** 다시 보낸다. F10은 창 부르기용이고, 창을 마우스로 눌러 질문해도 최신 상태를 쓴다 |
| 작업 상태 칸 | 모드 · 활성 물체(이름·종류·모디파이어 종류 목록) · 선택 물체 수와 이름 · 화면 언어 + 인터페이스 번역 켜짐 여부 · 열린 파일 경로(저장 전이면 비움) · 장면 물체 수 · Blender 버전 · 편집 모드 선택 방식(점·선·면)과 고른 개수 · 방금 실행한 조작 3개(이름만) · 활성 물체 배율(scale)과 크기. 편집 모드 개수 읽기 시간은 구현 때 잰다. 단계 완료 판정용 칸은 그 티켓에서 더한다 |
| 메뉴 이름 한국어 | 답 엔진이 바꾼다((a)안). 자료 준비 때 설치본 번역 사전(`blender.mo`)으로 설명서 메뉴 이름을 미리 대조. 번역이 하나면 그대로, **여러 개면 초보자 범위 안만 목록으로 뽑아 초반에 화면과 맞춰 검수·고정**, 범위 밖은 영어 그대로. 인터페이스 번역이 꺼져 있으면 영어만 |
| 답 | **스트리밍**(글자가 나오는 대로 표시). 근거는 답 끝에 한꺼번에: 소제목 경로, 영어 5.2 설명서 주소(소제목 위치까지), "그림 있음"/"영상 있음" 표시와 영상 링크. 오류·시간 초과면 짧은 오류 문구. 시간은 "첫 글자까지"와 "답 끝까지" 둘 다 기록 |
| Blender 여러 개 | 도우미 창 하나를 같이 쓴다. 애드온은 상태에 자기 Blender 창 번호를 붙여 보내고, 도우미 창은 **창 번호마다 최신 상태 하나**를 들고 있다. 질문을 보내면 마지막으로 앞에 있던 Blender의 상태로 답하고 Esc도 그 Blender로. 닫힌 Blender의 상태는 버리고, 마지막 Blender가 닫히면 도우미 창도 끈다 |
| 범위 밖 | 배포(답 엔진을 다른 PC에 두고 여러 사용자가 쓰기, API 키 한곳 관리) |

ADR은 만들지 않음: 한 프로그램 구성은 나중에 나누기 쉬워 되돌리기 어렵지 않다.
