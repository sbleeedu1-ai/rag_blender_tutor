# 21: 답 엔진 첫 왕복(가짜 모델)

Blocked by: 19
Status: ready-for-agent

근거: 명세 "답 엔진", 시험 경계 ①

## 만들 것

질문 + 작업 상태 → 검색 → 답 스트리밍 + 근거 목록. 답변 모델·임베딩은 밖에서 받아 테스트에서는 가짜를 끼운다.

## 완료 조건

- [ ] 검색은 임베딩 + BM25를 RRF로 합친 상위 6-8개.
- [ ] 답 글 조각이 흐름으로 나오고, 끝에 근거 목록(소제목 경로, `/en/5.2/<경로>.html#<앵커>` 주소, 그림/영상 있음 표시)과 검색 결과 목록이 붙는다.
- [ ] 질문당 호출이 임베딩 1 + 답 1, 꼭 2번인지 테스트한다.
- [ ] 오류·시간 초과 때 오류 표시가 나온다.
- [ ] 답 엔진은 아무것도 기억하지 않는다(최근 대화는 입력으로 받음).
