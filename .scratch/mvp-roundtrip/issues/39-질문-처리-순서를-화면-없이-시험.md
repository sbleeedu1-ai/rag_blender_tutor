## 만들 것

실제 AI를 붙이기 전에 질문 한 번의 정상·실패 처리와 시간 기록이 함께 맞는지 사람 확인 없이 알 수 있도록, 도우미 창에 흩어진 질문 처리 순서를 화면 없이 시험할 수 있는 한 module로 모은다.

지금은 `helper.py`의 `_ask`가 대상 Blender 고르기 → 작업 상태 확인(없으면 실패 안내) → 진행 단계 → 대화 실행 → 시간 기록 → 창에 보이기를 한꺼번에 한다. 창(PySide6)이 있어야 돌아서 이 순서는 자동 시험이 없다.

- 모은 module의 입구(interface)는 실제 창과 자동 시험이 함께 쓴다. 창 쪽을 바꿔 끼우는 자리(seam)에는 실제 창 연결과, 화면 없이 결과를 모으는 시험용 연결 두 가지만 둔다.
- 기존 `Conversation`(최근 대화)과 `Stopwatch`(시간 계산·기록)는 그대로 다시 쓴다.
- 창 그리기·Windows 초점·단축키·진행 판정 규칙은 대상 밖이다. 엔진 준비 방식은 C2(티켓 31·33)에서 따로 본다.
- 단순히 전달만 하는 함수를 한 겹 더 만드는 것으로 끝내지 않는다. 고칠 곳이 한곳에 모이고, 한 시험 틀로 여러 성공·실패 상황을 돌릴 수 있어야 한다.
