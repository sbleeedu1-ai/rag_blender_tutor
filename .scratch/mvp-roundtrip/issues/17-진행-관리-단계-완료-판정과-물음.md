# 17: 진행 관리 — 단계 완료 판정과 "다음 단계로 갈까요"

Blocked by: 15
Status: ready-for-agent

근거: 명세 "진행 관리", User Stories 39-44, 시험 경계 ②

## 만들 것

창과 떼어 둔 진행 관리 모듈. 작업 상태와 사용자 응답을 사건으로 받아, 띄울 물음·거둘 물음·지금 단계를 돌려준다.

## 완료 조건

- [ ] 끝난 조건은 AI 없이, 지금 단계의 조건만, 적힌 검사가 모두 맞아야 맞음으로 본다. 장면 물체 수는 단계 시작 때보다 늘었는지, 크기는 비율로 본다.
- [ ] 조건이 맞으면 "다음 단계로 갈까요" 물음을 돌려주고(창을 앞으로 끌어오지 않음), 답하기 전에 조건이 깨지면 거둔다.
- [ ] 한 단계에서 한 번 거절하면 그 단계는 다시 묻지 않는다.
- [ ] "다음 단계" 버튼, 건너뛰기, 뒤로 가기가 된다.
- [ ] 테스트는 상태 흐름과 응답을 차례로 넣고 나온 물음만 본다.
