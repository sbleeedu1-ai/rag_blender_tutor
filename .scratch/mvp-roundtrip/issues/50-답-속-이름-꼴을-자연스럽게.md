# 50: 한국어 화면 사용자가 답을 자연스럽게 읽도록, 모델이 지시를 어기고 남긴 이름 꼴을 화면 글자 한 가지 꼴로 정리한다

Status: ready-for-agent

근거: HISTORY [349]-[353]. 티켓 49([348])가 넣은 괄호 꼴("면(페이스, Face)")을 사용자가 "조잡"하다고 함. 지시문만 바꾼 시험은 스스로 옮긴 이름을 지금의 61-77%까지만 줄임([350]·[351]). 원하는 결과와 목표 꼴은 [353]에서 사용자가 정함.

## 원하는 결과([353])

메뉴·버튼·옵션 이름은 "화면 글자(영어)" 꼴로 화면에서 바로 찾을 수 있게, 문장은 사람이 읽기에 자연스럽게(겹친 괄호·지어낸 한국어·깨진 문장 없음). 화면 글자가 어색해도 화면 그대로. 지연 시간은 늘리지 않음(답마다 모델을 더 부르지 않음). 목표 54문항 중 50 맞음.

## 할 것(정한 꼴)

1. 가: 모델이 스스로 옮긴 이름 "직교 투영(Orthographic)" → 앞말이 그 이름을 흔히 옮기는 말일 때만 통째로 화면 글자 "정사법(Orthographic)". 흔히 옮기는 말 목록은 세 방법(① Haiku로 사전 이름마다 미리 한 번 만들기[유료, 돌리기 전 비용 확인] ② ko.po 설명 글 번역에서 뽑기 ③ 목록 없이 규칙)을 시험 결과의 읽은 자리(바꿀 것 178·바꾸면 안 될 ㉯)와 견줘 고른다. 시험 결과의 말을 목록에 직접 넣지 않는다(개발 문항에 맞춘 규칙 금지). 목록에 없을 때의 꼴은 미정(사용자 "지금 꼴 같은건 내가 이미 이상하다 말하지 않음?", `docs/agents/answer-forms.md` 미정 절).
2. 나: 감싼 이름 바로 뒤에 모델이 덧붙인 괄호("채우기(Fill)(단축키 Alt-F)", "스케일(Scale)(크기)") → 지시문에 "단축키·뜻 풀이는 이름 뒤 괄호에 붙이지 말고 따로 쓴다" 한 줄, 그래도 남으면 코드가 덧붙인 괄호를 지운다. → [409] 지시문에 넣었다가 [411]에서 뺌(단축키 괄호를 오히려 늘림, [410]).
3. 다: 위치 설명 뒤 괄호("파란 렌치 모양 탭(Modifiers)") → 지시문에 "위치 설명에는 괄호를 붙이지 않고 이름은 따로 [[ ]]로" 한 줄, 그래도 남는 자리의 꼴은 미정(위와 같음). → [409] 지시문에 넣음(11-17).
4. 라: 같은 이름이 한 답에 되풀이되면 처음 한 번만 "화면 글자(영어)", 다음부터 화면 글자만.
5. 공통: 바꾼 뒤 조사를 화면 글자 받침에 맞춘다("채우기(Fill)을" → "채우기(Fill)를").
6. 사전: 문맥마다 한국어가 다른 이름(속성 탭 Modifiers는 ID 문맥 "수정자", 일반 "모디파이어", 사용자 스크린숏)과 고정 짝 없는 이름(Union·Difference·Bake·Copy to Selected), 사전에 없는 이름(View Transform 등), 모델이 쓴 이름이 화면 칸 이름과 다른 것("Select Edge Rings"는 앞 'Select '를 떼면 "에지 링", 몇 개인지 셈)을 화면 코드·스크린숏으로 확인해 채운다.

나중(따로): 문장 속 일반 낱말(면 → 페이스, [78] 기준, 조사 함께, "화면·측면" 가림). 지시문 줄을 앞으로 옮긴 판 채택 여부는 마지막 유료 확인 때. → [407] [388] 점검표 순서로 옮김(자리만, 11-17).
