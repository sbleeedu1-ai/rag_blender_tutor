# 연습 과정 데이터 파일의 형식

Type: grilling
Status: open

## Question

연습 과정을 담는 데이터 파일은 어떤 형식인가? 구간·단계·조작을 어떻게 적고, 단계마다 무엇을 두는가(쉬운 설명, 먼저 볼 설명서 소제목, 끝난 조건, 목표 모양 설명과 참고 치수)? 검·방패 공통 1단계(공통 준비)는 어디에 두는가? 파일 하나를 더해 아이템을 늘릴 수 있어야 한다.

## 다른 티켓에서 넘어온 것

- (연습 과정 고르기) 구간 > 단계 > 조작, 진행·완료 판정은 단계 단위. 단계 = 눈으로 확인할 중간 결과 하나. 목표 모양은 말로, 치수는 참고로만. 시작은 기본 장면(정육면체가 칼날 시작), 1단계는 공통 준비
- (청크·검색 방식) 단계마다 연결한 설명서 소제목을 검색 "먼저 보기"에 쓴다
- (대화 기억 범위) 진행 기록은 연습 과정 이름·현재 단계·끝낸 단계 목록을 든다. 앞말 질문 검색에 현재 단계 이름과 연결 소제목을 붙인다
- (단계 완료 자동 판정) **끝난 조건**은 단계마다 있어도 없어도 되는 칸. 지금 단계 것만 보고, "방금 실행한 조작"과 묶고, 치수는 비율로만 적는다. 작업 상태에 재질 슬롯 수가 더해진다
- (확장 원칙, 지도 Notes) 코드가 아니라 데이터 파일로, 아이템을 바꾸거나 늘릴 때 파일만 더한다. 최종 목표(범위 밖)는 같은 형식을 AI가 만들어 내는 것이라 사람이 읽고 AI가 쓰기 쉬워야 한다
