# 18: 진행 관리 — 진행 기록 저장과 이어 하기

Blocked by: 17
Status: ready-for-agent

근거: 명세 "진행 관리"의 진행 기록, User Stories 46-50

## 만들 것

열린 파일 경로마다 진행 기록(작은 JSON, 사용자 설정 폴더)을 남기고, 파일을 다시 열면 이어 할지 묻는다.

## 완료 조건

- [ ] 다시 열면 "지난번 n단계(이름)까지 했어요. 이어 할까요?"를 한 번 묻고, 거절해도 기록은 지우지 않는다.
- [ ] 저장 전 진행은 메모리에 두었다가 처음 저장할 때 붙고, 다른 이름으로 저장하면 새 경로로 복사된다.
- [ ] 같은 파일에서 다른 연습 과정으로 바꿀 때 확인 물음을 돌려준다.
- [ ] 기록의 단계 이름표가 연습 과정 파일에서 사라졌으면 끝내지 않은 첫 단계로 가고 한 줄 알린다.
- [ ] 진행 기록에는 사용자가 확인한 것만 남는다. 테스트는 임시 폴더에 쓴다.
