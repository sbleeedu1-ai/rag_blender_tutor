# 대화 기억 범위

Type: grilling
Status: resolved
Blocked by: 05, 08

## Question

서버는 무엇을 얼마나 기억하는가(최근 대화, 현재 단계, 시도한 작업)? 앞말을 가리키는 질문을 검색어로 어떻게 바꾸는가?

## 다른 티켓에서 넘어온 것

- Blender를 껐다 켜고 저장 파일로 이어 할 때, 서버가 마지막 단계를 기억해 "이어 할까요?"라고 묻는다(연습 과정 고르기). 이 기억을 어디에 얼마나 오래 둘지
- 진행 기억은 단계 단위(조작은 기억하지 않음)
- (애드온 ↔ 서버 형식) 작업 상태에 "방금 실행한 조작 3개"와 열린 파일 경로가 온다. 시도한 작업 기억과 저장 파일로 이어 하기에 쓸 수 있다. 도우미 창과 답 엔진은 한 프로그램

## Answer

2026-10-19 사용자와 질문 라운드(Q1-Q10)로 정함. 참고: 이전 프로젝트(`rag_korea_history`)는 검색어를 AI로 다시 쓰지 않고 장면 설정 문장을 붙여 26 → 29/30. 모델 후보 조사에서 느린 원인은 추가 호출.

| 항목 | 결정 |
|---|---|
| 기억 위치 | **도우미 창 쪽**이 들고 질문마다 답 엔진에 넘긴다. 답 엔진은 아무것도 기억하지 않는다(평가·재현이 쉽고, 나중에 배포해도 사용자별로 나눌 필요가 없다). 형식 입력에 "최근 대화"와 "현재 연습 과정·단계" 두 칸을 더한다 |
| 기억하는 것 | **최근 대화**와 **진행 기록** 둘만. 시도한 작업은 따로 쌓지 않고 작업 상태의 "방금 실행한 조작 3개"로 대신한다 |
| 최근 대화 | 최근 **3쌍**(질문과 답 글만, 근거 목록 뺌). 설정값으로 두고 평가로 늘릴지 본다(사용자: 최종본에선 늘릴 수도). 도우미 창이 꺼지면 사라짐(파일로 안 남김). Blender가 여럿이어도 하나. 연습 과정 밖 자유 질문도 같은 최근 대화에 넣는다 |
| 앞말 질문 검색 | 추가 AI 호출 없이 현재 질문 + 직전 질문 + 현재 단계 이름과 연결 소제목 + 방금 실행한 조작 이름을 붙여 검색한다. 개발용 평가에서 자주 빗나가면 그때 검색어 다시 쓰기 호출을 시험한다 |
| 진행 기록 | 열린 **파일 경로마다 하나**. 사용자 설정 폴더의 작은 JSON(저장소 밖), 지우지 않고 계속 둔다. 내용: 연습 과정 이름, 현재 단계, 끝낸 단계 목록, 마지막으로 바뀐 시각. 저장 전에는 메모리에 두었다가 처음 저장될 때 그 경로에 붙이고, 다른 이름으로 저장하면 새 경로로 복사 |
| 이어 하기 | 진행 기록이 있는 파일을 열면 "지난번 n단계(이름)까지 했어요. 이어 할까요?"를 한 번 묻는다. 거절해도 기록은 지우지 않는다 |
| 같은 파일을 Blender 둘에서 | 막지 않고 나중에 바뀐 쪽이 덮어쓴다(Blender 파일 저장과 같은 방식) |
| 같은 파일에서 연습 과정 바꾸기 | 한 파일에 진행 기록 하나라 바꿔 쓴다. 바꾸기 전에 "이 파일의 진행 기록(검, 4단계)이 방패로 바뀌어요. 새 파일에서 시작하면 둘 다 남아요" 확인을 띄운다. 최근 대화는 그대로 이어 간다 |

단계가 **무엇으로** 넘어가는지는 「단계 완료 자동 판정」에서 정한다. ADR은 만들지 않음: 설정값·저장 위치는 나중에 바꾸기 쉽다.

사용자 말: "나중에 배포를 한다고 하면 서버측인 답 엔진에서 안 들고 있는게 맞겠죠? ... 가 방안으로 동의합니다", "최종본에선 좀 늘려야 할수도요 3쌍이면 은근 작다면 작은수라", "진행 기록이 사라질 수 있다 경고 정도는 보여줄수 있나요?", "용어도 그렇게 하죠"
