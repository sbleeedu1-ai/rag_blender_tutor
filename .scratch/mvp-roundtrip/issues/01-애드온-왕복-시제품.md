# 애드온 왕복 최소 시제품

Type: prototype
Status: resolved

## Question

Blender 5.2 애드온으로 다음이 실제로 되는가? 막히는 것이 있으면 MVP 형태를 어떻게 바꿔야 하는가?

- 단축키로 입력창 열기, N 패널에 채팅 표시
- 작업 상태(모드, 선택 물체) 읽기
- 고정된 답만 돌려주는 가짜 서버와 주고받기
- 요청하는 동안 Blender 화면이 멈추지 않는가
- 단축키부터 답 표시까지 걸린 시간(서버 시간 제외한 애드온 쪽 부담)

## 다른 티켓에서 넘어온 것

- 화면 언어(영어/한국어)를 애드온이 읽을 수 있는가(연습 과정 고르기)
- 두 번째 실행부터 뜨는 시작 창(최근 파일 목록)이 실제로 어떤지
- 강의실 PC(GTX 950 2GB)에서 Blender 5.2가 정상으로 뜨는가
- (화면 한국어 번역 조사) 화면 언어는 `bpy.app.translations.locale`로 읽고, `pgettext_iface`로 메뉴 이름을 바꿔 N 패널에 보여 보기. 한국어 화면에서 병합 메뉴 "At Center"와 새 Array 패널이 실제로 어떻게 보이는지 눈으로 확인
- Blender 5.2.2는 이 PC에 설치됨(조사 에이전트가 화면 없이 실행해 확인, 2026-10-19)

## Answer

2026-10-19 이 PC(강의실 PC: i7-4770, GTX 950 2GB, 16GB, Blender 5.2.2)에서 사용자가 직접 확인. 시제품 코드: 브랜치 `prototype/01-addon-roundtrip`의 `prototype/addon_roundtrip/` (커밋 0b10255, 192c873). 결정 기록: `docs/adr/0001-채팅은-Blender-위-도우미-창으로.md`

**결론: 질문 입력·답 표시는 Blender 안(N 패널)이 아니라 Blender 위에 떠 있는 작은 창(도우미 창)으로 바꾼다.** 애드온은 단축키, 작업 상태 읽기, 도우미 창 부르기만 한다.

| 확인 | 결과 |
|---|---|
| 강의실 PC에서 Blender 5.2 | 정상. 처음 켜면 빠른 설정 창, 다음부터 시작 창(새 파일 종류·열기·마지막 세션 복구) |
| 작업 상태 읽기 | 모드(`OBJECT`, `EDIT_MESH`)·선택 물체·화면 언어(`bpy.app.translations.locale`) 모두 됨. 한 번에 약 0.004ms |
| 가짜 서버 왕복 중 멈춤 | 없음. 기다리는 동안 화면 돌리기·물체 선택 가능 |
| 애드온 쪽 부담(서버 제외) | 15-64ms |
| **Blender 안 한글 입력** | **깨짐.** 질문 창·F2 이름 바꾸기 모두 글자마다 화살표를 눌러야 다음 글자로 감. 텍스트 에디터는 한영 전환 자체가 안 됨. Windows "이전 버전의 Microsoft IME 사용"을 켜면 거의 되지만 스페이스 두 번 필요 |
| Blender 안 질문 창 | Enter 두 번 눌러야 보내짐. N 패널은 한글 줄바꿈이 좁은 폭에서 잘림(한글 글자 폭 계산 필요) |
| **Blender 위 도우미 창**(Windows 설정 끈 상태) | F10 → 입력 가능까지 108-124ms, 클릭 없이 바로 한글 입력, Enter 한 번에 보냄, 줄바꿈 자동, Esc로 Blender에 바로 돌아가 조작 가능. 애드온이 `AllowSetForegroundWindow`로 허락해 주어야 창이 앞으로 나옴(성공 True) |
| 단축키 | F10(기본 키맵 3,095개와 겹치지 않음. F1·Ctrl+Shift+Space·Alt+Q는 이미 쓰임, Ctrl+Alt+T도 비어 있음) |
| 화면 한국어 | 병합 메뉴 At Center·At Cursor는 영어, 모드 이름 "에디트 모드", 추가 메뉴 한국어. 조사 결과와 같음. **모디파이어 목록에 "배열"과 "배열 (레거시)"가 둘 다 있음** |
| 새 물체 이름 | 한국어 화면에서 원기둥을 추가하면 "실린더". 작업 상태의 물체 이름이 한국어로 올 수 있음 |

도우미 창에 대해 사용자가 지적한 것(명세 세부): 창이 너무 커서 방해됨 → 작게, 나오는 위치는 정해진 자리에 고정. 창 크기는 조절되지만 작게 줄이면 입력칸이 안 보임 → 입력칸은 늘 보이게.
