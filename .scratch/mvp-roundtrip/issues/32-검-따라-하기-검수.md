# 32: 👤 검 따라 하기 검수

Blocked by: 24, 27, 28, 31
Status: ready-for-human

근거: User Stories 78-80, 명세 "연습 과정 파일"

## 할 것

사용자가 Blender 5.2에서 검 연습 과정을 처음부터 끝까지 따라 한다.

## 완료 조건

- [ ] 물음이 뜰 때마다 "방금 그 단계를 끝냈나" O/X를 남긴다.
- [ ] 막힌 곳을 기록한다(평가 문항 후보, 단계의 "자주 막히는 곳").
- [ ] 그때의 작업 상태 흐름 파일이 진행 관리 회귀 테스트로 들어간다.
- [ ] 검사를 통과하도록 검 파일을 고친다.

## Comments

- 2026-10-20 Claude(티켓 17에서 넘김): 검수 때 다시 볼 것. 물음에 [네]를 누르기 전에 다음 부품을 미리 붙이면, 진행 관리는 그 부품을 다음 단계에서 세지 않는다(누른 순간의 물체 수를 시작 수로 삼음). 그래서 "다음 단계" 버튼을 눌러야 한다. 반대로 물음이 뜬 순간의 수를 쓰면 미리 붙인 부품을 알아채지만, 실수로 더한 물체 때문에 물음이 잘못 뜨고, 거절하면 그 단계의 자동 물음이 꺼진다. 검수에서 어느 쪽이 자주 생기는지 보고 정한다(사용자: "일단 유지하고 검수단게에서 다시 볼것으로 두자"). HISTORY [26]
- 2026-10-22 Claude(티켓 22에서 넘김): 검수 때 검 파일 글의 Blender 용어를 화면 글자에 맞춘다. 파일은 꼭짓점(5번)·모서리(5번)·크기(9번)라 쓰는데 한국어 화면은 버텍스·엣지·스케일이다. 사용자가 도우미 말 그대로 되물으면 답 엔진이 메뉴 이름을 못 찾아 영어를 덧붙이지 못한다(사용자 동의: "2번 둘 다 동의해"). 화면 글자가 낯설면 "버텍스(꼭짓점)"처럼 함께 쓰는 것도 방법. 비슷한 말 표는 티켓 38. HISTORY [38]
- 2026-10-23 Claude(티켓 27에서 넘김): 조작 안내의 감지 조건을 검수한다. ① 조작 이름(mesh.loopcut_slide·transform.translate 등)이 사람이 직접 한 조작으로 실제 잡히는지 확인하고, 안 잡히면 감지를 지운다(그 조작은 [했어요]로 넘어감). ② **오탐**(하지 않았는데 했다고 넘어감)도 본다(사용자 요청: "방법 자체는 좋은데 확실히 이럴 위험은 있어보여서"). 지금 보이는 예: (크기 바꾸기는 조작 이름 대신 방향별 배율로 보게 고쳐 "길이를 늘였는데 폭 줄이기로 넘어감"은 막았다) "물체 모드로 돌아오기"(감지 모드 OBJECT)는 이미 물체 모드면 다른 것을 아무거나 눌러도 넘어간다. "새 원기둥 더하기"(감지 물체 수 늘어남 1)는 다른 물체를 더해도 넘어간다. 오탐이 잦은 조작은 감지를 지우거나 조건을 더 좁힌다. ③ 감지가 믿을 만하면 `blender_tutor/course_desk.py`의 `DONE_BUTTON_EVEN_IF_DETECTED`를 False로 바꿔, 감지되는 조작에서는 [했어요]를 숨긴다. ④ 공통 준비의 화면 조작 감지(`화면: 돌림·확대·축소·옮김·전체`, 시점 값 비교)를 실제 도우미 창으로 확인한다. 2026-10-23 기록기로 사용자가 직접 해 봤을 때는 휠·Ctrl+가운데 끌기·메뉴 Zoom·돋보기는 거리만, 가운데 끌기·색 공은 각도만, Shift+가운데 끌기·손바닥은 중심만, Home은 거리와 중심을 함께 바꿨고 마우스만 움직이면 아무것도 바뀌지 않았다(아이콘 끌기는 순서가 섞였을 수 있어 다시 본다). 오탐 후보: 숫자패드로 시점을 바꿔도 '돌림', 환경 설정에서 '마우스 위치로 확대'(Zoom to Mouse Position)를 켜면 확대 때 중심도 바뀌어 '전체'로 잡힘, 이미 장면이 다 담긴 채 Home을 누르면 아무것도 안 바뀌어 [했어요]가 필요함. ⑤ 크기 바꾸기 감지(`배율 늘어남·줄어듦`, 그 조작을 안내한 때의 같은 활성 물체 배율과 비교)를 S + 방향과 옆 패널 숫자 고치기 둘 다로 확인한다. 오탐 후보: 길이를 늘이다 실수로 폭도 조금 줄면 다음 '폭 줄이기'의 기준이 이미 줄어든 값이라 다시 줄여야 넘어감(놓침 쪽), 코등이·손잡이에서 S 한 번으로 모두 줄이면 바로 넘어감(감지 값이 '최소한 이 방향은 줄었다'만 봄). ⑥ 옮기기 감지(`위치 줄어듦: Z`)는 방향만 본다. 조금만 내리거나 너무 많이 내려도 넘어간다(예: 칼날 아래 끝 Z -3.5인데 코등이를 -1.0이나 -5.0에 둠). '아래 끝에 붙었나'까지 보려면 모든 물체의 실제 상자 자리와, 단계를 넘어 '이 물체가 코등이'를 따라가는 장치가 필요하고 지우고 다시 만들기·복제·되돌리기·합치기에서 어긋나기 쉬워 뺐다(2026-10-23 사용자 결정, 비슷한 장치를 한 번 찾아봤으나 없음). 검수에서 이런 실수가 잦으면 따로 티켓으로 만든다.
